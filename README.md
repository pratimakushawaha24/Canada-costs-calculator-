# Canada Cost & Service Calculator

A production‑ready Next.js website providing calculators and cost guides for Canadians.

## Features

- 30+ calculators (tax, mortgage, service costs, etc.)
- City and service pages
- SEO‑optimized
- Mobile‑first
- Search functionality

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Fuse.js for search
